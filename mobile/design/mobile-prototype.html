Society Mitra / Mobile UX Prototype

Interactive Mobile Design Specification - Reference for Flutter Development

Platform: Android + iOS (Flutter) Language: Bilingual EN + MR Theme: Dark Glassmorphism Version: 1.0 Date: June 2026

Design System / Design Tokens

  • Primary Gradient: #7C3AED (purple-600) -> #06B6D4 (cyan-500)
  • Background: #0A0A14 (near-black), Cards: #111827 (gray-900)
  • Text: #F8FAFC (primary), #94A3B8 (secondary), #64748B (tertiary)
  • Border radius: Cards 16px, Buttons 14px, Chips 20px, Inputs 12px
  • Spacing: Screen padding 16px, Card padding 16px, Gap 12px
  • Typography: Inter / System - Titles 22px/700, Body 14px/400, Captions 11px/500
  • Icons: Material Symbols Rounded, 24px nav, 20px inline
  • Bottom Nav: 5 primary tabs: Home, Notices, Grievances, Finance, More
  • Language toggle: Always visible in app bar or settings - EN | MR

6. Navigation Architecture

Information architecture and screen flow

Navigation Pattern: Bottom Tabs + Drill-down

  • Bottom Nav (5 tabs): Home | Notices | Grievances | Finance | More
  • Home tab: Dashboard with stats + quick action grid (8 shortcuts)
  • More tab: Grid of all 12 remaining modules + Profile + Settings + Logout
  • Each module: List View -> Detail View -> Edit/Action (push navigation)
  • Create actions: FAB (Floating Action Button) on list screens -> Bottom Sheet form
  • Back navigation: System back + left arrow in app bar
  • Language toggle: Available in Home app bar + Settings screen

Screen Flow Map

  • Login -> Register (3-step) OR -> Dashboard
  • Dashboard -> Any module via Quick Actions or Bottom Nav
  • Grievances: List (filter/search) -> Detail (timeline + actions) -> Create (bottom sheet)
  • Notices: List (filter) -> Detail (full notice) -> Create (admin only)
  • Finance: Summary card -> Bill list (filter) -> Bill detail -> Pay
  • Residents: Search/filter -> Profile card -> Call/Message
  • Polls: Active/Completed toggle -> Poll detail -> Cast vote
  • Vehicles: My vehicles list -> Add vehicle form
  • Meetings: Calendar view -> Meeting detail -> RSVP
  • Hall Booking: Calendar -> Time slot picker -> Booking form
  • Flats: Wing/floor grid -> Flat detail (ownership + history)
  • Inventory: Category list -> Item list -> Item detail
  • Bylaws: Document list -> PDF viewer
  • Tasks (Admin): Kanban or list -> Task detail -> Assign/Update

Design Principles Applied

  • Progressive disclosure: Most common actions on Home, rest in More tab
  • Thumb-friendly: Bottom nav, FAB for create actions, large touch targets (44px min)
  • Scannable: Color-coded badges for status/priority, card-based layouts
  • Bilingual-first: Language toggle always accessible, all content supports EN + MR
  • Dark theme: Matches web app aesthetic - glassmorphism with purple/cyan accents
  • Minimal cognitive load: One primary action per screen, clear hierarchy
  • Consistent patterns: Every module follows List -> Detail -> Create pattern
  • Accessibility: High contrast text, large fonts for elderly users, clear iconography

7. Component Library Reference

Reusable Flutter widget patterns

Flutter Widget Mapping

  • Bottom Nav: NavigationBar (Material 3) with 5 destinations
  • App Bar: SliverAppBar with custom title + actions (language toggle, notification bell)
  • Stat Cards: Custom StatCard widget - Container with gradient icon + value + label
  • Quick Actions Grid: GridView.count(crossAxisCount: 4) with InkWell items
  • List Items: Custom ModuleListTile - leading avatar, title, subtitle, trailing badge
  • Filter Chips: ChoiceChip in horizontal SingleChildScrollView
  • FAB: FloatingActionButton.extended with gradient decoration
  • Bottom Sheet: showModalBottomSheet with DraggableScrollableSheet
  • Cards: Container with BoxDecoration (borderRadius: 16, border: 1px solid #1e293b)
  • Inputs: TextField with custom InputDecoration matching dark theme
  • Badges: Container with color-coded background/text per status enum
  • Search Bar: SearchBar (Material 3) or custom with TextField
  • Language Toggle: SegmentedButton (EN | MR) connected to LocaleController

Color Tokens (for Flutter ThemeData)

  • primary: Color(0xFF7C3AED) — Purple 600
  • secondary: Color(0xFF06B6D4) — Cyan 500
  • surface: Color(0xFF111827) — Card background
  • background: Color(0xFF0A0A14) — Screen background
  • onSurface: Color(0xFFF8FAFC) — Primary text
  • onSurfaceVariant: Color(0xFF94A3B8) — Secondary text
  • outline: Color(0xFF1E293B) — Border color
  • error: Color(0xFFEF4444) — Urgent/Overdue
  • tertiary: Color(0xFF10B981) — Resolved/Paid/Success
  • Gradients: LinearGradient(colors: [primary, secondary]) for CTAs and accents

Typography Scale

  • displaySmall: 28px/800 — Screen titles (Dashboard)
  • headlineMedium: 22px/700 — App bar titles
  • titleLarge: 18px/700 — Card titles
  • titleMedium: 15px/600 — List item titles
  • bodyMedium: 14px/400 — Body text
  • bodySmall: 12px/400 — Descriptions
  • labelLarge: 13px/600 — Button text
  • labelSmall: 11px/500 — Badges, timestamps, captions
  • Marathi note: Devanagari renders ~10% wider; test all strings in MR locale for overflow
